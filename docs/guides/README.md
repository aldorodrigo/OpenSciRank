# Guías de uso — Editorial Standards Platform

Guías de usuario con capturas de pantalla para los dos roles operativos de la plataforma.

| Documento | Rol | Contenido |
|---|---|---|
| [`guia-editor.docx`](guia-editor.docx) | Editor | Registro, panel, asistente de revista (7 pasos), evaluación y sello, cambios, re-evaluación, libros (6 pasos), mensajería, pagos. |
| [`guia-evaluador.docx`](guia-evaluador.docx) | Evaluador | Escritorio, evaluación de revistas (17 criterios / 5 categorías), decisiones, solicitud de cambios, re-evaluación, mensajería, límites del rol. |

## Formato y edición

Los `.docx` son **editables** y se abren directamente en **Google Docs** (subilos a Drive y "Abrir con Google Documentos", o arrastralos: Drive los convierte) o en Word/LibreOffice. Están pensados como documento de trabajo para ajustar detalles antes de exportar el PDF final.

> Al abrirlos, actualizá la **tabla de contenido** (clic derecho → Actualizar campo / en Google Docs se regenera sola) para que refleje la numeración de páginas.

## Alcance

Esta primera versión **no** cubre la renovación del sello ni la consultoría; ambas están documentadas como issues aparte (renovación y consultoría) para agregarse cuando los flujos estén cerrados.
